# Penguin Birthday Surprise 🐧💖

A magical interactive birthday story and scrapbook web application built with **Next.js**, **shadcn/ui**, **Tailwind CSS**, and **pnpm**.

## Features

- **5 Interactive Story Scenes**:
  1. **Stage 1 (Pls Accept The Gift)**: Animated happy penguin with floating hearts and 3D Yes/No buttons.
  2. **Stage 2 (Why Did You Click No!)**: Heartbroken crying penguin with fountain teardrop animation and "Try Again".
  3. **Stage 3 (Choose a Penguin)**: 3 gift penguins with hidden secret love notes and sweet vouchers.
  4. **Stage 4 (Happy Birthday Cake)**: Party duckling, celebratory cake with interactive blowable candle, and "Click Me" candy heart.
  5. **Stage 5 (Scrapbook Journal)**: Two-page open scrapbook with heart-shaped photo frame, handwritten love letter, custom photo upload, ambient music box, and confetti showers.
- **Synthesized Audio Engine**: Web Audio API pop, sparkle, cry, candle blow, and celesta music box.
- **Particle System**: Canvas confetti and heart shower effects.
- **Modern UI Architecture**: Next.js App Router, shadcn/ui components, and Tailwind CSS.

## Getting Started

Run the development server with **pnpm**:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
pnpm build
pnpm start
```
